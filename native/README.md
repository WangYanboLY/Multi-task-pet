# Agent Pet 原生桌宠

这是 Agent Pet 的 macOS 悬浮界面。桌宠可拖动，并停留在普通窗口上方。光标移到桌宠上时会展开任务面板，移出桌宠与面板后自动收起。面板可手动刷新、打开带链接的对话，也可退出应用。

桌宠头上的绿色数字为运行中对话数（`working` 或 `waiting`），黄色数字为桌宠尚未标记已读的新回答数，蓝色数字为含有运行中对话的任务族数。

面板顶部有 `GPT` 和 `Claude` 两个来源。`GPT` 汇集 Codex 与 ChatGPT；`Claude` 汇集 Claude 网页、Claude 桌面 Code 与 Claude Code CLI。选定来源后，可选择“活跃对话”或“需要处理”。任务族卡片默认折叠，点击标题展开。首次打开时默认选择运行中对话最多的来源，数量相同则优先选择 `GPT`；手动切换后保留所选来源。

## 构建与运行

需要 macOS 13 或更新版本、Swift Command Line Tools 和系统自带的 `/usr/bin/python3`。无需 Xcode 工程或第三方依赖。

在本目录执行：

```sh
./build.sh
open 'dist/Agent Pet.app'
```

脚本将相邻的 `collector/collector.py` 放入应用的 `Contents/Resources`。启动应用时会启动采集器；退出应用时会结束它启动的采集器进程。应用不会设置开机自启。

## 数据展示

界面每 3 秒读取一次 `~/.agent-pet/tasks.json`。每条对话保留来源、状态、更新时间及可选的实际完成数；筛选后再依据 `family_id` 分组。

“活跃对话”包含 `working`、`waiting`，以及更新时间在今天且不晚于当前时间的非 `done` 对话。今天按电脑的本地时区判断；这一筛选不会改变绿色运行中数字的原有判断。“需要处理”包含 `waiting`、`failed` 和桌宠尚未标记已读的新回答；旧的 `idle` 对话不会自动进入。两种视图可能同时包含同一条记录。明确的 `done` 对话不会显示在“活跃对话”，但仍可作为未读回答留在“需要处理”。界面不推测没有可靠分母的完成百分比。Codex 采集器保留运行中任务与近 24 小时最多 8 条非运行记录。

桌宠观察到以前未记录的回答完成标记时尝试发送 macOS 本地通知，并将它加入黄色数字。首次建立观察基线时不会产生历史提醒。点通知或从面板成功打开 Codex／网页对话后标为已读；没有可打开入口的记录可手动点“标为已读”。桌宠无法可靠得知用户是否已经从其他应用打开并读过回答。

面板底部有随手想法输入框；发送后保存在本机 `~/.agent-pet/thoughts.jsonl`，历史可在面板内展开。未读状态保存在 `~/.agent-pet/read-state.json`。想法不会发送给模型服务。

Claude 和 ChatGPT 网页聊天仅覆盖已打开且安装浏览器伴侣的 Chrome/Edge 标签页。普通 Claude / ChatGPT 桌面聊天目前没有可靠的实时状态来源；界面不会将缺失数据解释成已完成。

面板显示每条对话的更新时间。网页对话的更新时间是浏览器伴侣最近观察到标签页的时间，并非最后一条消息的时间；今天仍打开的旧对话可能因此归入“活跃对话”。没有数据文件、空数据、读取错误和采集快照过期都有提示。关闭悬停面板不会退出应用；面板右上角电源按钮会退出应用。
