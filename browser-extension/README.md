# Agent Pet 浏览器标签观察器

这是 Chrome / Edge 的 Manifest V3 扩展。它只观察**已经打开**的 `chatgpt.com` 和 `claude.ai` 对话标签页，把对话 ID、网址、标题和保守判断的状态发给本机 `http://127.0.0.1:56987/event`。网址仅含对话路径，不含查询参数或片段。它不读取或发送消息正文，也不使用 API 密钥。

## 安装

1. 先启动 Agent Pet 本地收集器，确认它监听 `127.0.0.1:56987`。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，选中本目录 `browser-extension`。
4. 保持需要观察的对话标签页打开。安装时扩展会尝试注入到已打开的标签页；如果某个标签页没有出现，刷新该页一次。

扩展后台向本机收集器发送 JSON。收集器需要接受来自 `chrome-extension://` 或 `edge-extension://` 的 CORS 请求；网页本身不会直接连接收集器。

## 状态含义

- `working`：页面上看到了可见的“停止生成／停止回复”按钮。
- `waiting`：看到了包含明确“允许”和“拒绝”选项的可见决策对话框。
- `idle`：扩展在同一对话中先看到 `working`，随后看到停止按钮消失；这只表示**当前回复结束**。
- `unknown`：没有足够的界面证据判断当前状态，包括扩展刚开始观察一个已有对话时。

扩展约每 10 秒发送一次，并在检测到网址、标题或状态改变后提前发送。`observed_at` 是 Unix 毫秒时间戳。浏览器可能降低后台标签页的运行频率，因此收集器应根据这个时间戳把过期观察标为未知。网页界面变更也可能使按钮识别失效；本扩展不代表整个账号的聊天或任务清单。
